# Database Migrations

This directory contains SQL migration files generated by **Prisma Migrate**.

## Workflow

### Development

Run migrations from the `backend/` directory:

```bash
cd backend
npx prisma migrate dev --name <migration_name>
```

Prisma creates a timestamped SQL file at `backend/prisma/migrations/<timestamp>_<name>/migration.sql`.
Copy or symlink these into `database/migrations/` to keep a centralized audit trail.

### Production

Apply pending migrations without creating new ones:

```bash
cd backend
npx prisma migrate deploy
```

### Reset (Dev Only — ⚠️ Destructive)

Drop and re-apply all migrations:

```bash
cd backend
npx prisma migrate reset
```

### Inspect Schema

Open the Prisma Studio GUI:

```bash
cd backend
npx prisma studio
```

## Directory Layout

```
database/
└── migrations/
    └── <timestamp>_<name>/
        └── migration.sql
```

## Naming Convention

Use descriptive names: `init`, `add_users_table`, `add_rbac_tables`, `add_token_model`
